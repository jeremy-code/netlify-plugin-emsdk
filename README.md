Netlify build plugin that installs Emscripten emsdk.

## Installation

```shell
npm install netlify-plugin-emsdk # npm
yarn add netlify-plugin-emsdk    # yarn
pnpm add netlify-plugin-emsdk    # pnpm
```

## Usage

```toml
[[plugins]]
package = "netlify-plugin-emsdk"
```
